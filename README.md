# Outfitter with Microsoft

**Theme:** Build the Capability

A one-hour, VS Code–first training for people who build dashboards, apps, automation, AI agents, and code with GitHub Copilot.

The session focuses on personal and small-team productivity. Participants use Copilot Agent Mode to inspect, build, run, test, review, and package a realistic multi-source reporting workflow.

## Demonstration

The demo uses VS Code and Copilot Agent Mode to reconcile CRM, product-usage, alias, and prior-week data; preserve unresolved records as exceptions; calculate account-health indicators; generate a recurring report; add focused tests; and package the result with a runbook and reusable prompt.

All included data is synthetic.
