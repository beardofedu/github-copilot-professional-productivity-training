Start with work, not a feature

What kind of help do you need?

Choose a task you already understand and can verify. Good first tasks are repeated, bounded, and low-risk.

03
Worked example

Give Copilot less to guess.

Goal Create a script that identifies incomplete rows in a weekly CSV and writes a Markdown summary.

Context The columns are Item, Owner, DueDate, and Status. I run this manually on Windows every Friday.

Constraints Do not modify the CSV. Use built-in PowerShell features. Explain the approach before showing code.

Check Include a dry-run example and tests for valid, incomplete, and empty input files.

Tip

A prompt is not a one-time incantation. Ask for a plan, inspect assumptions, test a small result, and refine it.

05
Iterate

Make it a conversation.

  1. 1
    Ask for a plan

    Understand the proposed approach before creating anything.

  2. 2
    Inspect assumptions

    Find what Copilot guessed and correct what matters.

  3. 3
    Request a small first version

    Reduce risk and make the result easier to review.

  4. 4
    Test or verify it

    Use representative inputs, sources, or observable criteria.

  5. 5
    Share the exact result or error

    Specific evidence produces better troubleshooting.

  6. 6
    Refine what needs improvement

    Keep useful work and change only what is necessary.

06
Before you use or share it

Run the four-part verification check.

Confident language is not evidence. Open sources, inspect commands, and test results.
