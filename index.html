A repeatable prompt

Goal · Context · Constraints · Check

A simple pattern for turning a blank chat box into a productive conversation.

Goal

What outcome do I need?

Context

What must Copilot know about the source, audience, environment, or workflow?

Constraints

What must it use, avoid, preserve, or limit?

Check

How will I verify that the result is correct and safe?

From vague to useful

Give Copilot enough to work with.

Weak

“Make me a script for this report.”

Copilot must guess the goal, environment, boundaries, and success criteria.
Stronger

Goal: Find incomplete CSV records and write a summary.
Context: Windows; four known columns; run every Friday.
Constraints: Do not modify the source; built-in PowerShell only.
Check: Explain first; include tests for valid, incomplete, and empty files.

Responsible use

Keep ownership of the result.

Accuracy

Does it match the source and intended outcome?

Safety

Could it modify, overwrite, delete, or disclose anything?

Policy

Is the information appropriate to provide under organizational rules?

Fitness

Does it work in the real environment, not only in the example?

Confident language is not evidence.
